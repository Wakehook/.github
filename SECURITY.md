# Security

If you find a security issue in WakeHook or in any repository of this organisation, please **don't open a public issue**. Email **security@wakehook.com** with the details and, if you can, steps to reproduce. We'll acknowledge it and keep you posted. How WakeHook protects your data is described at [wakehook.com/docs/security.html](https://wakehook.com/docs/security.html).

Never post a real hook address, ping address or API key in an issue, pull request or discussion. Anyone who has one can page that team. If you've exposed one, generate a new address from its source page in the WakeHook dashboard.
